# rate-net v1.0.0 — Stable

**The public API is frozen until `2.0`.** The `0.9.5` release candidate soaked clean — no bugs, no friction from real consumption — and is promoted to `1.0.0` with no functional changes, only the status declaration and documentation polish. `rate-net = "1"` is the supported install from here on.

## What is rate-net?

A powerful, lock-free rate limiter for Rust. It answers one question as fast as the hardware allows — *"is this key allowed right now?"* — and returns a decision plus a `retry-after`, tracking an independent allowance per key. Five algorithms behind one `Limiter` trait, per-key state in a sharded store bounded by eviction, hardened against adversarial traffic, with a frozen public API validated against a representative gatekeeper consumer.

## The 1.0 line

The pre-`1.0` line that built this release, in one sentence each:

- **`0.1.0`** — repository bootstrap, dependency wiring, CI matrix, strict lint gate.
- **`0.2.0`** — public surface shape locked: `RateLimiter`, `Limiter`, `Decision`, `Quota`, `Algorithm`, `RateLimiterError`, `Key`, and the per-algorithm `proptest` over-admit invariant.
- **`0.3.0`** — sharded, bounded-memory per-key store with a `loom`-verified get-or-insert protocol and an allocation-free steady-state check.
- **`0.4.0`** — full algorithm suite (leaky bucket, fixed window, sliding-window log, sliding-window counter) behind the `Limiter` trait, plus the Tier-2 `Builder`.
- **`0.5.0`** — feature complete: `AsyncLimiter`, runnable `examples/`, the Criterion baseline.
- **`0.6.0`** — optimization pass (`ahash`, no redundant clock read on the hot path, `#[inline]`), with an honest head-to-head against `governor`.
- **`0.7.0`** — API freeze and the adversarial-traffic / edge-matrix `hardening` suite.
- **`0.8.0`** — first-consumer shake-out: representative gatekeeper coded against the trait, runnable `gatekeeper` example.
- **`0.9.0`** — beta: multi-threaded stress across every algorithm and compile-time `Send + Sync + 'static` for every public type.
- **`0.9.5`** — release candidate: documentation polish, RC declaration, RC-tag benchmark capture.
- **`1.0.0`** — stable. API frozen until `2.0`.

## Stability guarantees

- **Frozen public surface.** `RateLimiter` and its methods, `Builder`, `AsyncLimiter`, `Limiter`, `Decision`, `Quota`, `Eviction`, `Algorithm`, `RateLimiterError`, `Key`, `VERSION`, and the `DEFAULT_MAX_KEYS` constant are unchanged from `0.7.0` and are frozen until `2.0`.
- **`Send + Sync + 'static`** for every public type — enforced by the compiler, not just documented.
- **Never over-admits.** For any key and window, admitted requests never exceed the configured quota under any concurrent interleaving — proven per algorithm with `loom` and `proptest`.
- **Bounded memory.** Idle keys evict on an amortized, incremental schedule; a hostile unique-key flood reaches the cap and stays there.
- **Allocation-free steady state.** A `check` on an existing key allocates nothing.

## Benchmarks at `v1.0.0`

Criterion medians (Windows x86_64, Rust stable, `opt-level = 3`):

| Path | Median |
|------|-------:|
| Single-key check | ~54 ns |
| Many-key check (64 shards) | ~54 ns |
| Contended single key (4 threads) | ~54 ns/op |
| Eviction sweep (cold insert at cap) | ~217 ns |

All four held within ~±2 ns of the `0.6.0` baseline across the beta and RC soak — sample-to-sample variance, not regression. The honest head-to-head against `governor` is unchanged: rate-net's per-key overhead is competitive once the clock is held equal, and beating `governor` end-to-end still needs a fast TSC-style monotonic source in `clock-lib` (raised separately). Full method and analysis in [`docs/BENCHMARKS.md`](https://github.com/jamesgober/rate-net/blob/main/docs/BENCHMARKS.md).

## Breaking changes

None. No public items were added or changed from `0.9.5`. The frozen surface from `0.7.0` is unchanged through to `1.0.0`.

## Upgrade

Replace the pinned version. No source changes are required.

```toml
[dependencies]
rate-net = "1"

# Full algorithm suite + the async await-until-ready layer:
rate-net = { version = "1", features = ["algorithms", "async"] }
```

MSRV: Rust 1.85.
